# 结束回合前腾位：独立本地实验

冻结 v0.2 和原 practice 保持不变。本候选只通过实验入口加载，不切换默认版本，不连接竞技站。

## 假设与局限

新开发诊断（偏移 61000，三种对手各 128 局）显示：后期未到操作上限的结束回合中，
满场且手牌有数值评分更高随从的情况较常见；有空位却不打可用随从的情况没有观察到。
这只能支持研究替换时机，不能证明这些局面都决策错误。成长核心和触发器可能身材较小但很有价值。

候选 `EndTradePolicy` 在原网络选择结束回合时，若满场且手里有未锁定、零打出成本、
不会在本回合打出后死亡的随从，检查其冻结启发式评分是否至少比某个可卖随从高 10 且高 50%。
符合时让同一个网络在这些合法卖出动作中选择一个，每回合最多介入一次，至少保留四次原生操作。
之后继续原网络决策，不强制打出评分最高的手牌。

组合为 `RepeatGuard(EndTrade(Learned))`；不叠加移位退出或取消记忆。
权重、原 RepeatGuard 和评分函数均不变。这是推理规则实验，不是训练收益。
策略没有游戏句柄、隐藏对手手牌或随机状态。

## 固定协议

原始协议：`runs/end-trade-20261028/PROTOCOL.json`。

- 开发偏移 71000；每策略、每对手分布 128 局，共 768 局。
- 开发通过才使用验收偏移 130000；每策略、每对手分布 512 局，共 3072 局。
- 三类对手：脚本、冻结启发式、混合冻结学习对手；八席轮换，打乱行动轮次。
- 开发：等权平均名次差不超过 -0.05，各场景不超过 +0.15。
- 验收：平均差不超过 -0.10，95% 区间上界小于零；各场景区间上界小于 +0.15。
- 全部对局正常完成且零非法动作。失败不删除、不静默替换。
- 按完整八席种子块重采样，同种子的三类对手一起抽取；10000 次，统计 RNG 20261030。
- 不在本实验内根据结果调阈值。未达标不晋级，已用种子不再标为未见验收集。

## 运行与中断续跑

在仓库根目录执行，示例目录须不存在：

```bash
.venv/bin/python -m omnibob.economy_audit \
  --checkpoint runs/releases/omnibob-v0.2-20261028/policy/policy.pt \
  --policy-name end_trade --split dev --seed 71000 --games 128 \
  --opponents scripted --max-seconds 900 \
  --output runs/end-trade-repro/dev-scripted-end_trade \
  --stop-file runs/iteration-current/STOP
```

基线改为 `--policy-name baseline`，分别运行 `heuristic` 和 `mixed_learned`；混合学习对手增加：

```text
--opponent-checkpoint runs/releases/omnibob-v0.2-20261028/opponents/heldout-bc300/policy.pt
```

每局原子存储 `games/<seed>-<seat>.json.gz`，包括名次、失败状态、延迟、可见结束回合观测和腾位记录。
中断后先检查 `invocations.jsonl` 的实际 PID 是否仍活着；原进程结束后，用同一命令增加 `--resume`。
已尝试局不会重复运行；失败局仍保留。源码和运行合同发生变化会拒绝续跑。
停止文件只在局间检查；重新运行前需明确移除已不需要的停止文件。额度重置始终禁用。

同一协议目录下六组运行完成后生成判定（输出不可覆盖）：

```bash
.venv/bin/python -m omnibob.end_trade_report runs/end-trade-20261028 --stage dev
```

重新复现实验时先复制原 `PROTOCOL.json` 到新的实验根目录；这些已公开种子仅供复跑，不能作为新候选的独立验收。

## 开发结果：不晋级

768 局全部正常完成、零非法动作。每格 128 局，平均名次越小越好：

| 对手 | 冻结 v0.2 | 腾位候选 | 差值 |
|---|---:|---:|---:|
| scripted | 2.0078 | 1.9531 | -0.0547 |
| heuristic | 2.1641 | 2.1562 | -0.0078 |
| mixed_learned | 2.5391 | 2.5547 | +0.0156 |

等权平均差 -0.015625，完整种子块配对 95% 区间 [-0.067708, +0.036458]。
未达到预设开发改善 0.05 的门槛，拒绝晋级，未使用 final 偏移 130000。
候选未作为默认策略，也不叠加到其他候选。

脚本场景中收益最大/退步最大的各一局完整重跑，原名次均复现；
首次动作分歧前的可见观测摘要相同。收益最大局改善 3 名，退步最大局退步 1 名；
这些案例不用于修改本候选阈值。全部对照原始记录、延迟与诊断位于 `runs/end-trade-20261028/`。

118 项 Python 全量测试通过；随后新增报告完整性边界测试，3 项报告测试通过。
冻结 v0.2 权重 SHA256 仍一致。下一步采用有界 PPO 续训探针，不继续按数值评分修补此候选。
