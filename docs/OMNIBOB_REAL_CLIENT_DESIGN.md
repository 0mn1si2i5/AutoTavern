# OmniBob 只读实时建议

更新：2026-11-12。

产品循环：只读可见状态 → 用户快捷键请求建议 → 本地冻结模型 → 面板显示明确对象/位置/目标 → 人工执行 → 新状态与回执留档。工具独立于聊天运行，不生成任何客户端鼠标或键盘事件。

入口和可复制命令见 [实机工具说明](../tools/real_client/README.md)。默认发行仍由既有 `runs/releases/current.json` 选择，冻结 v0.2 和其他已发布权重保持原字节。

## 状态和建议

读取 GameState 与 PowerTaskList 事件，模型只接收展示层的本玩家区域和已经展示的选择。服务器选项只提供可用操作，不能覆盖实体实际区域。ChoiceCardMgr BEGIN 前的选项不进入模型。增量读取保留半行，日志切换或截断重建状态。已发送操作的旧选项表不能继续建议。

实时与回放共用 `public_view` 和 `Encoder`。回放停在每次发送之前，未来发送和结果不进入当前模型输入。日志末尾的选项列表只有完整换行并静默至少 300 ms 才补全。服务器/展示层未同步时显示等待。

建议包括来源卡牌、区域/槽位、目标与子选项。重复刷新相同状态复用原建议。输入状态变化、读取失败或推理期间发生状态变化，都会撤下旧建议。模型运行时的重复控制只在观察到匹配的执行回执后提交，用户按刷新键不等于执行模型动作。

## 尚未等价的输入

目前恢复本玩家核心区域、动态属性、关键词、资源、可用动作及显式选择；对手历史、部分附加效果和引擎累计计数未完整对齐。未知值逐项留档，`exact_training_observation` 为 false。冻结网络没有缺失值通道，因此此版本属于实验性迁移。面板必须显示这一点，不把能运行推理视作强度提升。

卡表需与日志 build 对应；模型训练规则还可能来自不同补丁。已知未知卡牌或关键字段缺失停止该帧建议，仍展示可恢复的局面。分支/目标推理基于操作前状态，不编造执行后的战吼效果。

## 留档与验证

会话保留来源字节、源码/模型版本、可见状态、模型输入、缺失清单、建议、观察到的实际动作、回执和人工标注。人工偏离模型建议独立记录，不能自动当作原策略轨迹训练或纯模型成绩。

本阶段只验证已归档示范局和只读面板，不训练、不做强度对局评测、不操作客户端。真实新对局中的快捷键使用和当前补丁机制覆盖需按实测状态报告。

## 移除与恢复

自动匹配、代打循环、鼠标点击/拖动与输入注入入口已退出产品路径。原始记录不删；旧工作区源码及未提交修改在 `runs/advisor-migration-20261112T072104Z` 保留可恢复快照。冻结权重和历史失败不能通过这次界面迁移改判。
