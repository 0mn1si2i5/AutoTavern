| 部分 | 上游实际具备 | OmniBob 本轮实现 / 差异 |
| --- | --- | --- |
| 游戏模拟 | Rust 完整八人对局、种子、存档、规则配置、脚本机器人 | 原生引擎和卡表不改；本机重新编译 arm64 release |
| Python | Game / BattlegroundsEnv / BatchEnv；245 动作；3227 浮点、124 卡牌槽位 | 独立策略边界、基线、完整对局驱动和配对评测 |
| 输入 | observe v1 玩家视角、合法 mask；layout、card_static 等 | 冻结布局/词表/引擎指纹；不用调试视图；复杂文本与可变长效果尚未建模 |
| 策略 | 廉价脚本 bot | 随机合法、上游 bot 比较器、自有 tempo-v0.1 启发式；没有训练成果 |
| 评测 | TavernBench 960 题、368 正式子集、答案、评分程序 | 本地对局 JSONL/汇总/失败记录/种子域/座位轮换/重放；Bench 仅供诊断 |
| 训练与模型 | 没有公开训练代码、TavernAgent 权重 | 本轮不实现完整 PPO；只有真实观测上的小型网络计算探针 |

论文第 6 节及附录 C 的核心是实体 Transformer（18M、d=384、8 层/8 头）、PPO、
终局名次效用、阶段间 KL 约束，以及用真实对局校准并隔离训练/考试来源的对手库。
附录 D 记录模型决策与人工按键执行；附录 F 的训练资源为 8 H200 和 128 CPU 核。
这些属于论文方法和报告，不是本项目达到的能力或算力。[论文 v1](https://arxiv.org/html/2610.33845v1)

尚缺：作者权重/训练实现、基准题生成器、可直接复用的校准对手库及其真实对局来源、
完整课程与终局效用的可执行配方、真实客户端观测适配与执行记录工具。
缺失材料需独立实现和验证，不能据论文表格反推已经复现。

主动简化：当前对手固定为七个脚本机器人；单进程评测；启发式策略；小网络仅作算子探针；
无文本 embedding、pointer head、校准对手库、辅助名次头和训练课程。
引擎默认线性名次奖励不是已核验的论文最终目标；后续若采用它，必须标为 OmniBob 自定实验目标。
简单自我对弈也不能替代论文的真实对局校准对手库。

与真实游戏/比赛的边界：本轮只验证本地模拟器与策略。竞技场公开协议已读取，版本差异见
[OMNIBOB_ARENA.md](OMNIBOB_ARENA.md)；尚未联网参赛，尚未人工执行真实游戏。
未来人工模式需逐决策记录可见输入、模型/规则版本、建议动作、实际动作、偏离原因、最终结果；
必须区分编码错误、执行错误、引擎差异和策略错误。
