## 为什么做

此前 PPO 续训候选在独立验收 3072 局中平均名次差为 -0.041016，95% 区间跨过零，未晋级。
一个可验证的差异是：原训练直接用引擎合法动作，而冻结部署通过 RepeatGuard 排除同一可见状态下已重复的动作。

48 局诊断中，原始贪心首选被部署掩码改变的比例分别为：脚本对手 31.49%、启发式 26.78%、混合学习对手 34.09%。
改变几乎都涉及移位。诊断器仍执行原部署动作；真实完整对局测试确认加诊断前后的动作、可见状态和名次一致。
这只证明部署路径上的行为差异，不能把这些比例解释成训练样本比例、策略损失或名次损失；每类只有两个完整环境种子块。

## 改动与单变量

`omnibob/training_repeat.py` 复用原 RepeatGuard，为每个学习环境维护独立历史，在采样动作前产生过滤后的合法掩码。
PPO 收集与更新都使用该掩码，避免采样之后替换动作造成概率记录错误。重复读取观察不会消耗历史；完整存档可恢复历史。
`TrainConfig.learner_repeat_limit` 默认 0，原训练行为不变；实验臂为 1。
模型、推理 RepeatGuard、引擎和冻结 v0.2 权重均未改动。策略只获取玩家可见观察。

三组训练种子为 96000000、97000000、98000000，每组两个臂，唯一配置差异为 `learner_repeat_limit=0/1`。
所有六个部署策略都使用 RepeatGuard=1，无额外移位控制器。对照臂也可晋级，不能为了支持对齐假说排除它。
每个臂固定 50 次更新、204800 次决策，32 环境 × 128 步；不挑中途 checkpoint。
首次两臂从已成功的三更新探针续跑 47 更新；其他四臂从同一个 v0.2 初始化。

短探针两臂分别用时 16.14/19.50 秒，峰值 RSS 1.04/1.15 GiB；MPS 驱动分配均为约 1.11 GiB。
RSS 与驱动分配不能当成不重叠的物理占用直接相加。对齐臂实际 12288 次采样决策中 439 次掩码改变，约 3.57%。
两臂均无错误、截断或丢弃。正式实验与 CPU 评测并发，用时不可直接与空闲机器探针对比。

## 运行和恢复

从仓库根目录运行。已启动任务不能直接重复执行 runner；先检查实际 PID、journal 和结果，保留所有失败尝试。

```sh
# 行为测试，包含完整对局透明诊断、真实循环和精确训练恢复
.venv/bin/python -m pytest tests/test_guard_audit.py tests/test_training_repeat.py tests/test_guarded_report.py -q

# 训练示例：新目录；配置固定为一个实验臂
.venv/bin/python -m omnibob.train \
  --initialize runs/releases/omnibob-v0.2-20261028/policy/policy.pt \
  --config runs/guarded-ppo-20261028/config-97000000-1.json \
  --rules configs/arena-v2.json --updates 50 --device mps \
  --max-seconds 900 --max-rss-gib 3 --output runs/my-new-alignment-training

# 全部对应阶段对局完成后生成报告；存在旧报告时拒绝覆盖
.venv/bin/python -m omnibob.guarded_report runs/guarded-ppo-20261028 --stage dev
.venv/bin/python -m omnibob.guarded_report runs/guarded-ppo-20261028 --stage final
```

若单个评测进程中断，核实进程确实终止后，使用 journal 中原始参数加 `--resume` 恢复那个目录。
已记录失败局会保留，不能删除后补跑成成功。正式固定更新未完成、源码/权重变化或评测缺局时，不输出晋级结论。
晋级后仍须完成离线接口一致性、兼容与可见信息检查、发行包校验和一条命令回退，再改变本地默认；不自动参赛。

## 可复用的离线接口检查

`omnibob.offline_check` 接收任意已导出的候选和已有己方观察记录，逐帧比较直接推理与官方协议适配入口。
它检查合法性、不同 match/seat 的控制器隔离、环境/卡表合同和部署权重不含训练存档，并保留失败报告。
结果目录包含 `frames.jsonl` 和 `summary.json`；不会联网、读取账号文件或发送动作。

```sh
.venv/bin/python -m omnibob.offline_check \
  --checkpoint runs/guarded-ppo-20261028/policy-96000000-arm1/policy.pt \
  --recording runs/practice-20261028-103720/policy/decisions.jsonl \
  --output runs/my-new-offline-adapter-check
```

这重放的是原策略经历的观察序列，候选没有重新改变游戏状态。检查通过只能证明适配一致、动作合法，
不能得出候选在这场 practice 的反事实名次，更不能替代最终完整对局评测。
