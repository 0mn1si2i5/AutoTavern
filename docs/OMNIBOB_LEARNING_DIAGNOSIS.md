# OmniBob 学习瓶颈诊断（2026-10-29）

本轮只做最长90分钟的诊断。**保留冻结v0.2，不晋级、不参赛、不启动下一轮训练。**

## 结论与优先级

**P0：优先改善每次策略更新所覆盖的独立对局信息。** 当前最明确的现象是更新能改善参与更新的数据，但迁移到其他轨迹的效果弱；环境之间的梯度一致性低。证据支持“有效学习信号相对采样噪声偏弱”这个方向，尚不能唯一确定根因，也不能据此宣布增加环境数会提高名次。

**P1：继续观察价值估计的跨局稳定性及长期信用分配。** 价值估计在接近终局时通常更准，远离终局时不稳定。但移除价值损失没有带来一致的额外策略收益，当前没有充分证据要求拆分网络或重写critic。

**P2：暂缓降低参考KL、扩大模型、继续加长训练。** 本轮没有支持“KL锁死学习”或“网络连基础数值判断都学不会”。上一轮已经证明512步提高终局覆盖率，但未建立额外名次收益；不能重复用这些机制指标代替实力。

## 实测证据

输入为冻结v0.2，以及128步、512步续训各三个固定200更新检查点。每份重新采集8环境×512步，使用训练域120000000–126000000的新起始种子、混合脚本/启发式对手、原始合法动作掩码。全部模型均未修改。

共28,672条己方可见决策、74次己方名次确定，其中48局已全部结束。余下轨迹允许在采样窗末尾bootstrap；这些不是“完成局”。真实采集零非法动作、零模拟器截断；这不是新的名次评测。

最后两列是PPO代理目标的改善，正值较好，**单位不是名次**。六条完整环境流参与更新，两条环境流留出；优势归一化只取拟合流的统计量。每个内存副本仅更新两轮、48个minibatch，不保存新权重。续训检查点保留Adam状态，冻结导出模型使用新Adam；不将两种优化器条件直接作因果比较。

- 拟合目标改善中位数0.013216，留出改善中位数0.000868；7组中2组留出反而变差。梯度在拟合/留出流之间的正负一致性与这7次实际更新结果一致。
- 512步三份模型的批均梯度信号/噪声粗估为0.134、0.135、0.050，环境间平均余弦仅0.011–0.036。估计仅有8条流，包含座位、局面和对局长度差异；不能当成总体参数的精确估计。负的信号平方估计表示估计噪声，不表示物理方差为负。
- 以上梯度使用训练器的全批优势归一化，流之间共享统计量。另用原始优势、去掉该共享统计量重算，512步三份的信号/噪声估计为0.133、0.145、0.172，仍低于1。该敏感性检查保存在`signal-raw-advantages.json`，没有新增采样或更新模型。
- 去掉参考KL后，留出代理目标相对原损失的额外改善均值为**−0.000017**，4组略好、3组略差，无一致收益。去掉critic项也无一致明显收益。全部短更新均未触发KL提前停止。短消融保留已有Adam动量，因此只用于判断当前更新的局部行为。
- 终局奖励逐条核对为`1−2×(名次−1)/7`，每步成本0.0003。用独立的TD残差有限和复算GAE，7组最大绝对误差均低于5.2e-7。正/负优势的动作概率更新方向、终局重置边界测试通过。
- CPU/MPS在64条真实观测上的最大概率差2.98e-7、最大价值差2.38e-7，策略梯度方向一致。没有观察到MPS导致的学习异常。

## 基础学习能力探针

构造可见商店：同种卡牌、同价，一张卡的攻击和生命都严格更高。任务仅为“若购买，选哪张”，不宣称这是完整战棋最优行动。标签来自己方可见数值，并逐条调用真实引擎购买，核对实际入手卡牌。

训练256个状态；新种子、未用于该探针训练的另一种卡牌、更大数值范围各留出256个状态。冻结v0.2在同卡新种子集上准确率89.45%，更大数值集83.98%；使用独立监督标签后，第25步起三个留出集合均为100%，固定第200步结果仍为100%。另一种卡牌的初始准确率已为100%，不把它报告为新提升。

整个探针10.60秒，学习率3e-4，仅证明当前输入、动作头和优化器能学习这一基础判断。它不是PPO胜率、不是自然对局分布，也不是可发布策略；没有导出权重。
